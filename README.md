# 🤖 Ask AI – Ask Anything. Learn Everything.

## 📌 About the Project

Ask AI is an FAQ-based educational chatbot developed using Python and Streamlit as part of the **CodeAlpha AI Internship**.

It helps students get answers to common programming and academic questions using a predefined FAQ knowledge base. It also includes text-to-speech functionality to read chatbot responses aloud.

## 🌐 Live Demo

🚀 **Try the application here:**

[Launch Ask AI Chatbot](https://ask-ai-chatbot-qsfctlkfu3mmkhjo7flyzz.streamlit.app/)

## ✨ Features

- 💬 Interactive chat interface.
- 📚 FAQ-based question answering.
- 🔍 Keyword matching and text similarity.
- 👋 Greeting support.
- 🔊 Voice output using gTTS.
- 💡 Suggested questions.
- 📝 Chat history.
- 🧹 Clear chat option.

## 🛠️ Technologies Used

## 🚀 Installation and Execution

**1. Clone the repository**

```bash
git clone https://github.com/ANITHA-R-1710/Ask-AI-Chatbot.git
```

**2. Navigate to the project folder**

```bash
cd Ask-AI-Chatbot
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```

**5. Open in your browser**

```text
http://localhost:8501
```

## 📚 Knowledge Base

The chatbot retrieves answers from `faq_data.json`, which contains predefined questions and answers related to:

- Python, Java, C and C++
- Artificial Intelligence and Machine Learning
- Data Science and Data Analytics
- SQL and DBMS
- Operating Systems and Computer Networks
- Cybersecurity
- Academic and career guidance

## 🔊 Voice Output

The application uses gTTS to convert chatbot answers into speech. An active internet connection is required for audio generation.
